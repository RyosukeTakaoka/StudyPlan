# UI の約束ごと（コンセプト画像への変更点）と確認リスト

コンセプト画像（[ui-concept.png](ui-concept.png)）のレイアウトと画面構成を踏襲し、次の点だけを変えています。
画像の筆跡は合成サンプルで、実機では撮影したカード画像に置き換わります。

## 1. 個性の出し方（3か所だけ）

| 指示 | 実装 | 場所 |
|---|---|---|
| アクセント色を1色に統一（深い青 #2B4C9B、ダークでは少し明るく） | ライト #2B4C9B／ダーク #5E7FD6。ボタン・「今」の印・選択状態はすべて `Theme.accent` | `Shared/Assets.xcassets/AccentColor`, `Shared/Theme.swift` |
| 完了の演出：線を左→右へ0.3秒以内、軽い触覚 | 0.25秒で線を引き、`.impact(weight: .light)`。「視差効果を減らす」がオンなら線を引かずにすぐ表示 | `App/Components/Flourishes.swift`（`CompletionStroke`） |
| 「今のブロック」の印：マーカーの下線（静的、手書き風はこれだけ） | 形を固定した下線 `MarkerUnderline`。動かさない | 同上（`nowMarker`） |

## 2. 守るルール

- **手書き風フォントは使わない**：文字はすべてシステムフォント（サンプルの合成画像もシステムフォントで描いています）。
- **演出は1画面に1か所まで**：
  - 今日（iPhone）：「今」の印は、今のブロックが「予定」のときだけ。実績を記録すると印は消え、完了なら線が出る。
  - 今日（iPad）：下の欄で完了の線が出ているあいだは、一覧の「今」の印を出さない。
  - カード詳細：完了の線だけ。確認画面・設定・見返し・比較・検索には演出を入れない。
- **確認画面・カード詳細・設定は標準的な iOS の見た目**：`List`（insetGrouped）／`Form`／`LabeledContent`／segmented `Picker`。
- **演出をすべて外しても使える**：設定 →「完了の線と『今』の印」をオフにすると、線・印・触覚が消えます。状態はボタンの枠と太字、タグの文字とアイコンで分かります。

## 3. 区分の見分け（色だけに頼らない）

色・SF シンボル・文字ラベルの3点で区別します（`Shared/BlockCategory.swift`）。色は彩度を抑え、アクセント色の青とも離しています。

| 区分 | シンボル | 色（ライト／ダーク） |
|---|---|---|
| 勉強 | book.fill | #5A6A85 ／ #A3B0C8 |
| 仮眠 | moon.zzz.fill | #766C93 ／ #B3AACB |
| ゲーム | gamecontroller.fill | #8E6470 ／ #CDA3AE |
| プログラミング | chevron.left.forwardslash.chevron.right | #4F7A6E ／ #95BFB2 |
| 移動 | figure.walk | #857348 ／ #C8B78C |
| 固定予定 | pin.fill | #6B6B70 ／ #AEAEB4 |
| 休憩 | cup.and.saucer.fill | #8A6A52 ／ #C9AA92 |

選択状態も色だけに頼らず、「アクセント色・太字・枠の太さ」の3つとアクセシビリティの「選択中」で示します。
確認画面の「要確認」は、落ち着いた背景に、アイコンと理由の文字で示します。

## 4. 文字の大きさ

- すべてテキストスタイル（`.body`, `.headline`, `.subheadline`, `.footnote` など）。固定サイズは使いません。
- 下限：一覧は `.subheadline`、補足文字は `.footnote` を最小とし、`.caption` 以下は使いません。さらに「今日の流れ」・補足文字・設定などに `readableFloor()` を付け、端末の文字を小さくしても標準サイズより小さくなりません（`Shared/Theme.swift`）。
- Dynamic Type を大きくすると、横並びは縦並びに切り替わります（`AdaptiveStack`, `SectionHeader`, `ViewThatFits`。状態ボタンは 4列 → 2×2 → 縦1列）。

## 5. ウィジェットの筆跡

- カード全体を縮小せず、**インクのある領域を切り出して**表示します（`App/Services/ImageUtilities.swift` の `InkCropper`）。
- 画像が小さくて読めないときのため、**タイトルの文字起こしを必ず並べて**表示します（`Widget/NowNextWidget.swift`）。

## 6. 確認リスト（実機で確かめること）

Xcode では TodayView のプレビューで、ライト／ダーク・大きな文字をすぐに見られます。

- [ ] ダークモードとライトモードの両方で、各画面の見た目を確認する（今日・撮影・確認・詳細・比較・検索・設定・ウィジェット）
- [ ] 設定アプリ → アクセシビリティ → 画面表示とテキストサイズ → さらに大きな文字 を最大にして、崩れないか確認する
- [ ] 設定アプリ → アクセシビリティ → 動作 →「視差効果を減らす」をオンにして、完了の線がアニメーションせずに出るか確認する
- [ ] 実際のホワイトボード写真に差し替えて、カード・ウィジェット（小・中・ロック画面）で筆跡が読めるか確認する
- [ ] アプリの設定で演出をオフにして、普通に使えるか確認する
- [ ] 1週間使って、演出が邪魔にならないか確認する（気になったら、演出の設定や `CompletionStroke` の太さ・時間を調整）
